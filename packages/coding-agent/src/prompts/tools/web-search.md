For known URLs or structured endpoints, use `read`.
Query syntax: `site:` or `-site:`, `after:` or `before:` `YYYY-MM-DD`, `inurl:`, `intitle:`, `filetype:`, `"phrase"`, `-term`, `OR`.
{{#if xSearch}}
X posts and reactions → `site:x.com`, `site:x.com/<handle>`, or `from:<handle>`; `-from:<handle>` excludes a handle.
{{/if}}
Hacker News threads/comments → `site:news.ycombinator.com`.
Favor primary sources; MUST include citation links.
