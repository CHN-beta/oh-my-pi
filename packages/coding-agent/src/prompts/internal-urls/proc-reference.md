proc://<id>/streams enumerates a bash job's pipes and redirected output files, and proc://<id>/streams/<n> reads data written through stream n so far. Writing sends stdin to services only (an empty write sends Enter); proc://<id>/mode accepts `persist|session|detached` (services only); launch long-running processes as named services when stdin or lifetime management is needed. Finished jobs are evicted (process-local).
